# Домашние задания по Samsung Innovation Campus

## Как устроен репозиторий

### Папки

- **Module1** — папка с заданиями 1 модуля.  
  Остальные папки с `Module` будут аналогичны (задания определённого модуля).
- **1.1, 1.2, ...** — папки, которые внутри содержат файлы с кодом (ответы) на задания определённого пункта в модуле.

### Файлы

**`Test_a_b_c.java`** — непосредственно файлы заданий.

Где:
- `a_b` — задания определённого пункта в модуле (например, `1.1` или `1.2`)
- `c` — номер задания

**Пример:**  
`Test_1_2_4.java` — файл с кодом для теста в теме 1.2 и номером задания в тесте 4.

**`TestDop_a_b_c.java`** — непосредственно файлы доп. заданий.

Где:
- `a_b` — задания определённого пункта в модуле (например, `1.1` или `1.2`)
- `c` — номер задания

**Пример:**  
`TestDop_1_2_4.java` — файл с кодом на дополнительный тест в теме 1.2 и номер задания в тесте под номером 4.
