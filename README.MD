Как устроен репозиторий:

Папки:

Module1 - папка с заданиями 1 модуля
Остальные папки с Module будут аналогичны (задания определенного модуля)

1.1 - ... - папки, которые внутри содержат файлы с кодом (ответы) на задания определенного пункта в модуле

Файлы:

Test_a_b_c.java - непосредственно файлы заданий.
Где:
a_b - задания определенного пункта в модуле (к примеру 1.1 или 1.2)
c - номер задания

Пример:
Test_1_2_4.java - файл с кодом на тест в теме 1.2 и номер задания в тесте под номером 4

TestDop_a_b_c.java - непосредственно файлы доп. заданий
Где:
a_b - задания определенного пункта в модуле (к примеру 1.1 или 1.2)
c - номер задания

Пример:
TestDop_1_2_4.java - файл с кодом на дополнительный тест в теме 1.2 и номер задания в тесте под номером 4.
